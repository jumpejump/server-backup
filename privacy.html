jumpejump（以下「運営者」）は、個人用アプリserver-backupについて、以下のとおりデータを取り扱います。

1. 利用目的と対象

本アプリは、運営者本人のサーバーにあるファイルを、本人のGoogle Driveへバックアップし、必要に応じて復元するために利用します。第三者向けのバックアップサービスは提供していません。

2. Googleのデータへのアクセス

GoogleのOAuth認証により許可を得たうえで、drive.fileスコープを使用します。本アプリが作成したGoogle Driveのファイルについて、バックアップの保存・復元・整合性確認・保存世代の整理に必要な範囲で、内容およびファイルID、ファイル名、サイズなどのメタデータにアクセスします。

3. 保存と保護

バックアップ対象のファイル内容と復元に必要なメタデータは、resticによってサーバー上で暗号化してからGoogle Driveへ送信します。Google Drive上では暗号化されたバックアップファイルと、そのサイズなどの保存管理情報が扱われます。

OAuthの認証情報および復号用パスワードは、運営者が管理する環境でアクセス権を制限して保管します。これらはこの公開ウェブサイトには保存しません。復号用パスワードは、復旧に備えて運営者が別途安全な場所にも保管します。

4. 共有と利用の制限

Google Driveはバックアップ保存先として利用します。GoogleのAPIから取得したデータを販売したり、広告、第三者向けの分析、AIモデルの学習に使用したりすることはありません。

Google APIから受領した情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

5. 保存期間、削除、アクセスの取り消し

バックアップは運営者が設定した世代管理方針に従って保持・整理します。運営者はバックアップ処理を停止し、Google Drive上の保存データを削除できます。

Googleアカウントのサードパーティとの接続から本アプリへのアクセスを取り消すことができます。アクセスの取り消しだけでは、既にGoogle Driveへ保存したバックアップは削除されません。

6. このウェブサイトについて

このサイトには独自のアクセス解析、広告、入力フォーム、ログイン機能を設けていません。公開にはGitHub Pagesを利用し、ホスティング事業者がセキュリティなどのためアクセス情報を処理する場合があります。詳しくはGitHubのプライバシーに関する声明をご覧ください。

7. お問い合わせと変更

運営者：jumpejump。お問い合わせはGitHub Issuesへお願いします。秘密情報や個人データを公開の投稿へ含めないでください。本ポリシーを変更した場合は、このページと更新日を更新します。
